- **Maintain Developer Docs**: As the project progresses, you **MUST** keep the project context files inside the [**`developer_docs/`**](file:///d:/F%20drive/client%20projects/pnp/pawns-poses-insight/developer_docs) folder up to date.
- **Log New Milestones**: When you implement a new feature, perform a major refactoring, or modify database models/APIs:
  - Update the [**`0_SUMMARY_OF_DEVELOPMENT.md`**](file:///d:/F%20drive/client%20projects/pnp/pawns-poses-insight/developer_docs/0_SUMMARY_OF_DEVELOPMENT.md) roadmap and files list.
  - Create a new numbered context file (e.g., `5_NEW_FEATURE.md`) detailing your changes, architectural decisions, and verification results.
- **Design System Consistency**: If you introduce new visual styles, update layouts, or create UI primitives, ensure they are documented in [**`design-system/pawnsposes/COMPONENTS.md`**](file:///d:/F%20drive/client%20projects/pnp/pawns-poses-insight/design-system/pawnsposes/COMPONENTS.md) and conform to [**`design-system/pawnsposes/MASTER.md`**](file:///d:/F%20drive/client%20projects/pnp/pawns-poses-insight/design-system/pawnsposes/MASTER.md).
